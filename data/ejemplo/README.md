# Datos de ejemplo (ficticios)

Para probar el sistema sin escribir datos a mano, copie los cuatro archivos `.json` de esta carpeta a `data/`:

```bash
cp data/ejemplo/*.json data/        # Linux / macOS
copy data\ejemplo\*.json data\    # Windows (cmd)
```

Contienen 5 productos, 2 clientes, 3 ventas y sus movimientos. Los resultados esperados de los reportes están en `docs/pruebas.md`.
Todos los datos son inventados; no hay información personal real.
